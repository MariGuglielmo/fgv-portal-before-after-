# FGV Ensino Médio Portal Redesign

Interactive before-and-after view of the redesign of FGV Ensino Médio, a national educational platform with more than 120,000 registered users.

Project lead: Mariana Guglielmo

The redesign included requirements definition, information architecture, separate user experiences for students, teachers, and schools, testing, and final functional approval in collaboration with FGV's IT team and an external design firm.
